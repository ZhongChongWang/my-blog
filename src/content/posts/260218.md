# 第二准备安装

如果你的电脑的cpu是x86的按照我的做:
按照我给你的下载地址安装或与我给你的安装地址过时了这是[Debian的官网](https://www.debian.org/distrib/)注意要选:**安装前先体验 Debian Live现场版**下的任意一款带图形化的安装

## u盘安装

u盘选择合适的姓名以及个性化选择安装

## 拔出u盘

最后一部,拔出u盘,给你的用户增加root权限

1. **切换到 root 用户：** 在终端输入 `su -`，输入安装时设置的 root 密码。
2. **安装 sudo（如果未安装）：** `apt-get install sudo`。
3. **将用户加入 sudo 组：** `usermod -aG sudo 用户名` (将“用户名”替换为你的实际用户名)。
4. **生效：** 注销并重新登录系统。
5. **测试：** 使用 `sudo -i` 切换到 root，或在命令前加 `sudo`。

你可以看电视了
